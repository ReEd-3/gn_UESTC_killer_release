# 晚安成电killer · 发布仓库
# 【讣告】

> **【重要通知】自动打卡功能已失效（2026-10-23 起）**
>
> 学校服务端在打卡提交接口新增了「来源校验」：提交时必须携带由**微信小程序原生环境**签发的操作票据（`X-Checkin-Ticket`），且服务端会对其验签。该票据无法在小程序之外生成或获取，因此本应用**已失去自动完成打卡的核心能力** —— 提交请求一律被服务端拒绝（`code=46001`，「请从微信小程序重新进入打卡应用后提交」），与 UA、请求头、登录会话是否有效均无关（均已实测）。
> 目前尚未找到有效应对手段，所有人，作哀！

## 📲 下载安装

1. 点击进入 [最新版本 Releases](https://github.com/ReEd-3/gn_UESTC_killer_release/releases/latest) 页面，在「Assets」中下载 APK 文件
2. 在手机上打开安装（首次需在系统设置中允许「安装未知来源应用」）
3. 系统要求：**Android 8.0 及以上**
4. 后续版本可直接覆盖安装升级（签名一致）

## 🚀 使用步骤（简版）

1. 打开应用，阅读并确认首次弹出的「使用须知」
2. 点击「登录账号」，在页面中完成一次学校统一身份认证
3. 点击左上角 ☰ →「权限检查」，按引导授予：精确闹钟、电池优化白名单
   （国产系统还需在系统设置中允许「自启动」「后台运行」）
4. 保持「后台自动打卡服务」开启 —— 之后每天到点自动打卡，无需打开应用

更详细的说明与常见问题（到点没打卡怎么办 / 如何修改定位 / 更换手机等）见源码仓库 README。

## 🔒 隐私与安全

- 登录会话、运行日志等敏感信息均使用 Android 系统密钥库（Keystore）**加密存储**，仅本机应用可读取
- 应用**不收集、不上传任何个人信息**；打卡请求由手机直接发送至学校服务器
- 开发者承诺不窃取、不泄露用户的任何隐私信息
